## 社区热议

- **小米 MiMo-V2.6 发布，官方已确认。** Pro、Flash 均为全模态模型，官方同步开放模型权重、技术报告、强化学习环境及训练代码。Artificial Analysis 公布的测评中，Pro 的 Intelligence Index 得分为 **46**，发布时位居开放权重模型首位；其总参数为 **1.02 万亿**、激活参数为 **420 亿**。
- **Grok 4.7 的第三方测评同时显示能力提升与用量增加。** Artificial Analysis 在 xhigh 推理设置下测得 Intelligence Index 为 **46**；配合 Grok Build 的 Coding Agent Index 为 **56**，较上一代提高 9 分。其 Intelligence Index 每项任务平均输出约 **8.1 万 token**，对照的 Grok 4.6 high 为约 **3.6 万 token**；两者推理设置不同。
- **Hermes 的 Claude 订阅插件由开发者账号公布。** Teknium 宣布提供 `claude-subscription-directsdk` 插件，让 Hermes 经官方 Claude Code 客户端使用 Claude Pro／Max 订阅，同时保留 Hermes 的工具与审批流程。官方文档将其标为**实验性**，模型可用范围和额度仍受账号订阅规则约束；这不是 Anthropic 官号发布的集成公告。[官方文档](https://hermes-)
- **Superset 发布 iPhone 版本。** 用户可远程控制电脑上运行的智能体，并在手机上审查、提交 PR。
