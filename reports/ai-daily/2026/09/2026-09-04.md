## 社区热议

- **Claude Code Function Hooks：官方开发者账号称仍在探索，尚未发布。** 
 Anthropic 开发者账号 @ClaudeDevs 展示了 Function Hooks 的演示视频。该功能旨在让用户通过钩子扩展和定制 Claude Code，但原帖明确表示目前尚未上线，并邀请用户在 GitHub issue 中反馈。<br>[GitHub 讨论](https://github.com/anthropics/claude-code/issues/91870)

- **ChatGPT 付费计划的 Astra 补偿额度：员工补充信源，非 OpenAI 官号确认。** 
 OpenAI 员工 @thsottiaux 发帖称：对于每天无法使用 Astra 的付费 ChatGPT 计划用户，将按缺失天数提供一个 **banked reset**，首个 reset 预计在发帖后约 3 小时到账。原帖没有明确说明该 reset 对应 ChatGPT 的哪一项具体额度，也不能据此写成所有订阅档位均已自动重置。<br>

- **SpaceXAI 确认 Grok 服务曾受计算中心故障影响，现已恢复。** 
 @SpaceXAI 表示，Memphis 计算中心当天发生故障，导致部分用户使用 Grok 时遇到问题；官方随后称所有系统已恢复并正常运行。<br>

- **Claude Fable 5.1 / Mythos 5.1：社区传闻 / 未确认。** 
 第三方账号 @venturesintern 在 9 月 3 日的 AI 新闻汇总帖中声称 Anthropic 发布了 Claude Fable 5.1（GA）和 Mythos 5.1（受限开放），并提到面向编码、智能体和研究任务。检索 @AnthropicAI 与 @claudeai 后，未找到对应的官方确认，因此不计入「各公司动态」和一句话总结。<br>
