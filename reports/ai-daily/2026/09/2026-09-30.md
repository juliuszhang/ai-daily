## 社区热议

- **Pro 200 用量调整——员工补充说明，不是额度重置。** @thsottiaux 表示，重新开放的 200 美元 Pro 订阅将改变用量计算方式，按 API 标价折算的可用金额约为旧方案的一半，同时不恢复 5 小时限额。这不等于无限用量，原帖也没有宣布为所有订阅统一重置额度。

- **dots 的“不占额度”有明确边界。** 社区讨论了 dots 随订阅提供的使用权益；官网确认，与 dot 对话不计入 ChatGPT 使用上限，但它启动或管理的 **Codex、ChatGPT Work 任务仍照常计量**。订阅包含深度工作的额度，发布首月另有扩展额度，并非所有任务无限使用。[官方已确认](https://openai.com/index/introducing-dots/)

- **Codex 与开发者 API 的配套更新，官网已确认。** @thsottiaux 介绍了新版 Codex Cloud 和支持电脑操作的 Agents API。官方 DevDay 汇总进一步列出：可复用的云开发环境；支持语音和 `/agents` 多任务视图的新 CLI；覆盖 GitHub、GitLab 的代码审查；支持多智能体、工具搜索和上下文压缩的 Agents API；在 AWS 内运行的 Bedrock Managed Agents。另有 **Decisions API 限量预览**，使用 Luna 根据文本或图像上下文，从预设答案中完成分类、路由或行动选择。[官方汇总](https://openai.com/index/devday-2026-recap/)

- **DevDay 的协作与插件功能，需区分已开放和预告。** 社区整理了 ChatGPT Space、Pages、团队任务、Slack／Teams 接入，以及插件侧栏扩展、插件创建与发现改进、Sites 嵌入插件和 MCP Events 自动化。官网确认，Space、Pages 面向 Pro／Business／Enterprise；团队任务及 Slack／Teams 接入面向 Business／Enterprise；**多人协作 Slides 要在未来数周开放**。Meetings 插件目前为 macOS 桌面端 Pro／Business 测试功能，Enterprise 尚待开放。企业隐私方案 Private Intelligence 同时公布，Private Inference 预览计划于秋季推出。[官方已确认](https://openai.com/index/devday-2026-recap/)

- **ChatGPT 订阅跨工具使用与企业采购接入。** @thsottiaux 介绍了在第三方产品中使用 ChatGPT 订阅的方式；官网列出 **16 家合作伙伴**，包括 Devin、Notion、Vercel、T3、OpenClaw、Dactyl，参与工具中的合资格用量计入 Plus／Pro 原有额度，用户可控制各工具的用量。另有 OpenAI Marketplace，首批列出 **32 家合作伙伴**，符合条件的企业客户可申请将部分既有采购承诺用于合作方软件；这与个人订阅共用额度是两套机制。[官方已确认](https://openai.com/index/devday-2026-recap/)
