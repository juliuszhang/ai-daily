# 今日 AI 圈速报 · 2026-09-23

**一句话总结**：OpenAI 发布 GPT-6 Sol 和 Luna，降低 API 价格并接入 ChatGPT Work 与 Codex；Anthropic 发布 Claude Opus 5.5，同时提高订阅使用上限、提供可留存的额度重置机会。

## 社区热议

- **OpenAI 订阅额度重置——员工补充信源**：@thsottiaux 于北京时间 **9 月 23 日 02:23** 表示，正在向所有 **Plus、Pro、Business** 用户账户发放一次可留存的重置机会（banked reset）。这不是“所有订阅额度已经统一自动重置”；原帖未分别说明 Codex、ChatGPT Work 的适用额度池，也未给出发放完成时间或使用截止时间。

- **Claude Agent SDK 的形式化验证实践**：Boris Cherny（@bcherny）展示了使用 Opus 5.5 和 Lean 检查 Claude Agent SDK 的过程，称几条简短提示产生了 **16 个修复缺陷和竞态条件的 PR**。他还介绍了结合 Lean 与 TLA+ 检查数据流、并发和状态管理问题的做法。

- **第三方评测对比 GPT-6 Sol、Luna 的成本与得分**：Artificial Analysis 发布对比结果，称两款模型在其 Intelligence Index 中与前代得分接近，测试成本约减半，主要原因是 token 定价下降。
