## 社区热议

- **Codex / Work 改进与重置计划｜员工补充信源**：OpenAI 团队成员 @thsottiaux 于北京时间 10 月 5 日 04:33 表示，未来 28 天每天将二选一：交付一项对多数 Codex / Work 用户有明确帮助的改进，或进行一次“完整重置”（full reset）。原帖未列明重置的具体额度类型、适用订阅档位及每日执行时间，也没有宣布所有用户的额度已经统一重置。

- **Synara 发布 v1.0.0 Beta**：@trySynara 公布新版本，新增 Hubs，由协调智能体与最多 8 个并行工作智能体协作，支持共享记忆和持久化任务队列；同时加入任务待办、统一收件箱、多服务商账号管理，以及同一会话内跨服务商移交上下文。Beta 版还提供 CI 自动修复功能，须等待审批，且不会自动合并代码。

- **开发者分享 Claude Code 调用 Codex 浏览器扩展的方案**：@argofowl 展示了通过 MCP 代理连接 Codex 的 Chrome 扩展，让 Claude Code 操作多个 Chromium 浏览器的做法，并利用扩展实例 ID 区分浏览器。这是开发者自行搭建的集成方案，并非 OpenAI 或 Anthropic 宣布的新功能。
