## 社区热议

- **The X Subscription 上线，已获官方确认。** Cursor 官号宣布接入统一订阅。付费个人套餐月价分别为 Plus **8 美元**、Premium **30 美元**、Super **100 美元**、Ultra **200 美元**，未含税；产品间共享每周用量池。Plus 仅支持 Grok 模型；Premium 及以上可在 Cursor 使用第三方模型，但需按 API 标价另付费用，并包含 Grok Bot。现有订阅可选择保留原套餐；账户合并不可撤销，通过 Apple App Store 购买的 Cursor 订阅需要自行取消。[官方价格页](https://cursor.com/pricing) · [账户合并说明](https://docs.x.ai/x-subscription/unify-accounts)

- **Meta 发布 Muse Wonder 双模型，已获官方确认。** Muse Wonder 已在 Meta Model API 和 Muse Code 提供；Muse Wonder Full 已向 Muse Code 订阅用户提供。官方介绍了跨对话检索相关上下文的 **Active Memory**，以及支持长任务持续执行、尝试替代路径的 **Active Focus**；Muse 应用接入仍将先向订阅用户逐步开放。Artificial Analysis 同日公布，两款模型在其 Intelligence Index v4.3 上分别获得 **52** 和 **56** 分，均为最高推理强度配置。[官方研究博客](https://research.meta.ai/blog/muse-wonder)

- **Artificial Analysis 推出 AA-3D 评测。** 该评测要求模型在离线沙箱中将文字需求制作成可交互的 three.js 场景，包含 **55 道任务、7 个领域、21 个模型**，依据超过 **1,000 名评审的 10,000 次有效投票**排名。首批结果中，Claude Sonnet 5.5、Claude Opus 5.5、GPT-6 Astra 与 Claude Fable 5.1 位于榜首组，置信区间重叠，不能仅凭 Elo 点估计认定其中一个显著领先。

- **Artificial Analysis 新增 FrontierCode 1.1 排行榜。** 此次新发布的是排行榜，而非重新发布已有基准。评测使用 **100 道私有任务**，同时检查单元测试、修改范围及代码能否满足维护者合并要求。Claude Opus 5.5 的综合得分为 **52%**；GPT-6.1 Sol 为 **49%**，评测记录的单任务成本为 **0.81 美元**。

- **额度专项：OpenAI 员工讨论 Pro 用量方案，未宣布重置。** Codex / ChatGPT 团队成员 **@thsottiaux** 提及，为 Pro 100/200/500 档位恢复 **5 小时限制**、换取 **两倍周用量**的设想，并表达对用户反馈的意外。该帖属于员工讨论，不是已实施的套餐调整，也没有宣布统一自动重置、人工重置安排或重置时间。
