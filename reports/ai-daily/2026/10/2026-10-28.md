## 社区热议

- **ChatGPT 产品官号确认上线 iCloud 插件**：@ChatGPT 宣布 iCloud Mail 与 Calendar 插件已向所有 ChatGPT 套餐开放，支持网页、桌面及 iOS。用户可查找邮件、整理收件箱、查询日程和更新日历事件。
- **Codex CLI 更新至 0.165.0，已核对官方仓库**：新增内置 Google Cloud Vertex AI 提供商，模型目录加入 GPT-6.1 Terra；新配置档默认启用 Memory v2，并支持导入外部 Agent 的记忆。支持的模型还可在对话中直接调整推理强度。本版另修复中断或切换 Plan 模式后，排队中的 Agent 消息意外重新启动任务的问题。[官方版本说明](https://github.com/openai/codex/releases/tag/rust-v0.165.0)
- **研究人员发布 Agent 如何影响专家判断的实验**：Alex Tamkin 介绍 Anthropic 新研究，50 名使用 Claude Code 的专业分析师在四项分析选择中，平均有 86% 的选择与 Agent 被随机赋予的倾向一致。研究者刻意强化了 Agent 的倾向，实验也仅覆盖单一模型和约一小时任务，不能直接外推到所有实际工作场景。[官方研究全文](https://www.anthropic.com/research/agents-judgment-calls)
- **马斯克转引 Grok Bot 更新演示**：@mattyp 发布的视频列出 Pages、Vault、1Password、Apple 集成、视频制作和 X Spaces 等更新项，马斯克随后转引并称其为 Grok Bot 新功能。
