## 社区热议

- **Claude Code 调整上下文工程方式，官方资料已确认。** Anthropic 的 Claude Code 工程师 Thariq Shihipar 表示，团队为 Claude 5 系列模型削减了超过 **80%** 的 Claude Code 系统提示词，编码评测未出现可测量损失；新的实践更强调模型判断、工具接口设计、按需加载 Skills 和自动记忆，并新增 `claude doctor` 用于精简 Skills 与 `CLAUDE.md`。｜[Claude 官方博客](https://claude.com/blog/the-new-rules-of-context-engineering-for-claude-5-generation-models)

- **社区传闻/未确认：Grok 4.6 与 4.7 发布时间表。** Elon Musk 发文称 **Grok 4.6 将在两周后推出、Grok 4.7 将在四周后推出**。 截至本次检索，@SpaceXAI 未提及这两个版本，x.ai 官方站也没有对应发布或时间表，因此尚不能视为 SpaceXAI 官号正式确认。

- **Hermes Agent Skills 完成集中整理。** Nous Research 联合创始人 Teknium 发布 Skills 全面整理动态，涉及内置与可选 Skills 的升级、重组和清理；检索到的维护者信息显示，本轮合并了 **24 个 PR**、审查约 **145 个 Skills**，并同步 **26 个 Skills** 至较新的上游工具版本，@NousResearch 随后转发相关内容。｜

- **Drone-Bench 发布。** Andon Labs 发布面向 AI 编程智能体的无人机任务基准，要求智能体为自主无人机编写并验证监控任务代码，用于考察长链路软件工程和现实环境约束下的执行能力。

- **智能体基础设施出现两项新产品。** HarnessRouter 发布统一 API，用于将 Codex、Claude Code、Hermes 等编码智能体接入应用；Mitosis Labs 发布语音优先、无传统界面的本地智能体 Yappy，用于处理表单、邮件和仪表盘等电脑任务。｜

## 总体趋势观察

1. **前沿模型竞争同时转向能力、成本和运行效率。** Claude Opus 5 的发布重点不仅是评测成绩，也包括单位任务成本、推理 token、速度及长时间智能体任务的稳定性。

2. **智能体工程正在从“堆叠提示词”转向环境和接口设计。** Claude Code 的上下文精简、Hermes Agent 的凭证隔离，以及 Grok Build 的搜索插件，分别对应上下文管理、安全边界和外部工具接入。

3. **安全能力逐渐进入智能体运行时层。** Hermes Agent 将真实凭证隔离在 Docker 沙箱之外，反映出具备代码执行和网络访问能力的智能体开始需要专门的凭证代理与出站控制机制。

4. **过去 24 小时的官方动态集中度较高。** Anthropic 发布完整的新模型，SpaceXAI 和 Nous Research 更新智能体生态；OpenAI、Google DeepMind、智谱、DeepSeek、Qwen 与 OpenClaw 官号未发布符合条件的实质动态。
