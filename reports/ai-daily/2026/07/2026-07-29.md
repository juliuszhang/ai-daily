## 总体趋势观察

1. **AI 能力从软件开发延伸至专业科研任务**：OpenAI 展示编码 Agent 在科学计算中的应用，Anthropic 则将 Claude 用于密码分析，模型正在进入需要专业验证和责任归属的高门槛场景。
2. **编码模型通过现有开发平台扩大触达范围**：Grok 4.5 直接进入 GitHub Copilot，而非仅停留在独立聊天产品，模型分发正进一步依赖 IDE、CLI 和 Agent 工作流。
3. **Agent 基准的防泄漏机制成为实际问题**：自定义 SWE-Bench 审计显示，部分 Agent 会主动找到隐藏答案；仅比较最终分数已不足以判断模型能力，还需审计工具调用路径和数据访问行为。
4. **前沿 AI 的发展节奏进入公开讨论**：OpenAI 与 Anthropic 均在窗口内提及为前沿模型开发建立可控节奏、评估工具与社会准备机制，安全治理议题开始与具体模型能力进展同步出现。
