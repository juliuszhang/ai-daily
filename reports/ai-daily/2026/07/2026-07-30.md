## 社区热议

- **T3 Code 推出移动端远程控制。** 项目开发者 Theo 宣布 T3 Code 已登陆 iOS 和 Android；在终端运行 `npx t3 connect` 后，可通过手机远程控制 Claude 与 Codex。项目继续采用免费、开源模式。

- **Claude Code 的结构化输出 Skill 获得集中讨论。** 社区传播的 `i-have-adhd` Skill 会要求 Agent 先给答案、命令、路径或代码片段，再分步骤解释；每一步只包含一个明确动作，并在回复末尾给出一个可立即执行的下一步。

- **Claude 与 Codex 交叉核查插件出现。** Research Council 插件让 Claude 和 Codex 分别完成研究，再读取、核查并修订对方报告，最后由 Claude 汇总结果，目标是通过异构模型交叉验证减少遗漏。

- **超大开源模型的低内存运行实验。** 社区开发者展示了在单台 128GB MacBook 上运行 Kimi K3 的实验：模型权重按需从 Hugging Face 流式读取，仅将当前需要的部分保留在内存中；作者同时说明该方案推理速度较慢。

- **Grok Voice 的 Agent 基准表现受到讨论。** Elon Musk 发帖称 Grok Voice Think Fast 2.0 在 Agent 任务测试中位列第一；该表述来自其对第三方基准分析的转述，不属于 @SpaceXAI 官号发布的量化结果。

## 总体趋势观察

1. **Agent 性能越来越取决于完整运行栈。** OpenAI 的 ARC-AGI-3 结果显示，推理状态保留、上下文压缩和 API 选择可以显著改变同一模型的成绩与 Token 消耗，评测重点正从单纯比较模型扩展到比较 Harness。

2. **推理成本优化进入产品级落地阶段。** GPU Kernel 与推测解码带来的直接成本下降，说明前沿实验室正在把模型辅助系统优化转化为可量化的生产收益。

3. **实时语音 Agent 开始形成明确商业接口。** Grok Voice 提供按分钟计费的 API；Hermes Agent 则补齐本地唤醒和工作空间集成，分别代表云端商业化与本地自主控制两条路线。

4. **编码 Agent 的使用界面继续向终端之外扩张。** 移动端远程控制、双模型交叉核查和结构化回复 Skill，正在把 Codex、Claude Code 等工具从单一编码助手扩展为可组合、可远程操作的开发工作流。
