## 社区热议

- **Codex 安全缓解措施：OpenAI 员工补充说明。** OpenAI Codex 团队成员 @thsottiaux 回顾了近期针对误删用户文件风险推出的措施：要求 Codex 在删除前检查目标、创建新的临时目录、避免复用 `$HOME` 等系统环境变量；同时加强高风险命令拦截、Full access 权限提示、Auto-review、针对性评测和训练数据过滤。帖子提到，问题模式包括清理临时目录时错误指向用户主目录。<br>

- **Codex / ChatGPT “重置按钮”并非额度重置公告。** @thsottiaux 发布了收到实体“reset button”的帖子，并随后用 Codex 作比例参照发布照片。原帖是玩笑性质，没有宣布任何统一的额度重置、人工重置机制、适用订阅档位或具体重置时间；用户回复中的“约 19–20 小时后重置”也不是 OpenAI 官方产品公告。<br>

- **GLM-5.3 的缩放路线讨论。** 智谱创始人 @jietang 发文称，GLM-5.3 与 GLM-5.2 使用相同的基础模型、架构、总参数量和激活参数量，主要通过一个月的长时程环境训练与强化学习进行后训练；帖子将其描述为检验“后训练缩放”效果的受控实验。该信息来自创始人账号，并非 @ZhipuAI 在本窗口内的公司官号帖子。<br>

- **DeepSeek Harness v0.1.0-rc.8：社区传闻/未确认。** @wquguru 发帖称，版本加入原生多模态适配器、按需安装的 Claude Code 与 Codex 子代理配置、Windows 持久化终端、并发工具调用、会话分叉和更小的安装体积等功能。过去 24 小时内未检索到 @deepseek_ai 对该版本的对应确认，以上内容不作为 DeepSeek 官方发布结论。<br>
