## 社区热议

- **OpenAI 员工账号公布一次性 “banked reset”**：@thsottiaux 表示，所有付费的 **ChatGPT Work 与 Codex 用户**都会获得一次可自行使用的 banked reset，计划在 **2026 年 8 月 21 日太平洋时间晚上 8 点前后**到账。该消息描述的是一次性额度赠送，不是所有订阅的自动周期重置。 
 他此前还表示，Codex 活跃用户已达到 2,000 万，并称正在调查部分用户反馈的使用限额消耗异常。

- **Ox Alpha 的模型归属仍未确认**：社区围绕匿名模型 Ox Alpha 展开讨论，相关帖子称其在 OpenRouter 和 OpenCode 提供限时免费预览，具备约 1M token 上下文，并支持文本、图像和视频输入，重点面向长程编程与 Agent 工作流。部分社区账号将其猜测为 GLM 系列变体，但未获 @ZhipuAI 官方确认，因此标注为**社区传闻/未确认**。

- **Grok 4.6 的编程评测与成本数据受到讨论**：Elon Musk 发文称，Grok 4.6 在 CursorBench 3.2 中以 70.8% 得分排名第一，单任务成本为 2.81 美元；相关比较还列出 Fable 5 Max、Opus 5 Max 和 GPT-5.6 Sol Max 的成绩与成本。

- **X Ads 开放 Agent 通过 MCP 管理广告**：Elon Musk 账号发布的信息显示，Grok、Grok Build、Claude Code 等 Agent 可以连接 X Ads，执行广告数据查询、分析、创建和管理等操作；相关工具数量为 23 个，新建广告活动默认处于暂停状态。
