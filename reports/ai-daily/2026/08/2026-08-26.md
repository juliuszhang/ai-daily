## 社区热议

- **Perplexity 官方发布 Portable Computer。** 该产品运行在 NVIDIA DGX Spark 上，将编排模型、子模型和 Agent Harness 全部部署在本地；当前提供本地安装的 **PPLX 27B** 与 Qwen 3.8 27B，支持在用户授权后将复杂任务升级到云端模型。官方称该功能已向 Perplexity Pro 和 Max 用户开放。<br>

- **Codex 与 Claude Code 的集成说法正在传播，但官方账号未直接确认。** 社区帖子称 OpenAI 弃用 `codex mcp-server`，改用基于双向 JSON-RPC 的 Codex App Server，并建议 Claude Code 用户使用 Codex 插件；目前检索到的直接来源为社区账号，未找到对应的 OpenAI 官方账号帖子，因此标注为「社区传闻/未确认」。<br>

- **MiniMax 展示 M3 的实际任务成本。** MiniMax 官方账号称，M3 完成“创建收件箱、撰写并发送商务邮件”的端到端任务成本为 **0.018 美元**，并将其描述为当时该基准中成本最低的模型。该帖子属于性能案例展示，不构成新模型发布。<br>

- **ChatGPT Business Premium Seats 的补充信息。** OpenAI 员工 @thsottiaux 表示，该 100 美元席位计划面向团队和小企业，包含 ChatGPT、ChatGPT Work 与 Codex 功能，并支持 Google Workspace、Slack、GitHub、Microsoft 365、SAML、SSO、MFA、集中计费和使用分析；该席位不设 5 小时限制。<br>

- **额度重置专项监控：** 过去 24 小时内未发现 @thsottiaux 发布新的统一额度重置或周期重置公告。
