## 社区热议

- **Codex 额度消耗问题**：OpenAI Codex 与 ChatGPT 团队成员 Tibo（@thsottiaux）表示，部分用户本周的缓存命中率低于此前几周的稳定状态，这可能导致 Codex 使用额度消耗更快；团队正在调查，并计划发布后续更新。该帖讨论的是缓存命中率和额度消耗，没有宣布统一重置。<br><

- **OpenAI Codex 开源项目受到讨论**：X 社区围绕 < 展开讨论。相关帖子将其描述为使用 Rust 编写、运行在终端中的 coding agent，并称开源重点是 Codex harness，而不是早期 Codex 模型本身。<br><

- **Agent harness 被视为性能关键因素**：@lukeNukemAI 发文称，同一模型在不同 harness 下的真实任务得分可能相差约 2 倍；@Usefulatlas 提出，coding agent 的执行环境应支持隔离和回滚，因为 agent 会犯错；@AleksejAros 建议从任务完成、工具与状态连续性、失败恢复与验证、人工介入成本等维度评估 agent。<br>< · < · <

- **Grok Bot 使用案例**：Elon Musk 在 X 上推广 Grok Bot。相关帖子展示了用户让 Grok Bot 整理桌面文件，以及并行执行 X 与网页研究、筛选信息和生成简报等任务。<br>< · <
