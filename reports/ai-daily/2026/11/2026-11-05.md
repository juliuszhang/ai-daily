## 社区热议

- **Claude Code 后台子智能体减少额度消耗**：开发者账号 @ClaudeDevs 披露，子智能体每 30 秒更新状态时，已从重读整个对话改为由 Haiku 5.5 根据简短笔记撰写状态。其称单次状态更新成本降低约 99%；这一数字不代表整个任务或订阅总用量降低 99%。
- **员工说明：Claude Code 调整游戏开发限制**：Addy Osmani 表示，2.1.317 修改了此前导致部分原创游戏项目被拒绝的规则；用户可引用已有游戏来说明玩法类型，但要求复制原作时，模型会转而提出类似的原创方案。
- **Google 官号确认 Voice Remixing 已开放**：Gemini 3.8 Flash TTS 的声音重混功能已在 Google AI Studio 和 Gemini API 上线，可从 2,000 多种预设声音或自定义声音出发，用提示词调整音色、音高、语速和口音。
- **管理层补充：Pierre 团队加入 OpenAI**：Greg Brockman 称 Pierre 的开源开发工具已用于 Codex 的部分功能，并将继续合作开发 AI 软件协作工具。
- **开发者试验 DeepSeek 与 Claude 的分工**：@thdxr 表示，团队本周正在尝试将子智能体切换到 DeepSeek Flash，仅在主智能体保留 Opus 5.5。
